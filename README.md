# Julia — Assistente RAG per ricette di dolci

Assistente conversazionale che consiglia ricette di dolci usando un sistema RAG
(Retrieval-Augmented Generation) in locale con Ollama.

## Stack
- Node.js
- Ollama (`nomic-embed-text` per gli embedding, `llama3.2:3b` per la generazione)

## Stato
Progetto in ricostruzione, tracciato passo per passo.
